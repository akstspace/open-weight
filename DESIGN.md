# OpenWeight Design System

This application uses the **Moss** design system from Chai Studio.

**Preset:** `built-in-moss`  
**Description:** Forest green and muted earth product UI.

## Source of Truth

The canonical design tokens are managed in Chai Studio and rendered via the `chai-studio_get-design-doc` MCP tool. Do not edit this file to change colors, typography, or component styles — update the preset in Chai Studio instead.

## Typography

- **Body / Heading:** Public Sans
- **Mono / Labels:** IBM Plex Mono
- **Label caps:** IBM Plex Mono, 0.75rem, weight 600, letter-spacing 0.12em, uppercase

## Radius

- **sm (4px):** inputs, buttons, checkboxes, badges
- **md (8px):** cards, dialogs, alerts, dropdowns
- **lg (12px):** large cards, primary containers
